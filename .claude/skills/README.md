# Vendored skills

These skills are vendored from [mattpocock/skills](https://github.com/mattpocock/skills)
(MIT licensed, © Matt Pocock). They live here — rather than being installed via
`/plugin` — so they load automatically in every Claude Code session for this repo,
including ephemeral Claude Code on the web sessions where `/plugin` isn't available.

Each subdirectory is a self-contained skill with a `SKILL.md`. Claude Code discovers
them automatically; no configuration is required.

To update, re-copy the skill folders from the upstream repo's `skills/engineering/`
and `skills/productivity/` directories.
